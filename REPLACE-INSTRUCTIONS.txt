PORTFOLIO REPLACEMENT
=====================

This ZIP is designed to be extracted into the root of your existing Astro repository.

It replaces/adds:
- src/
- public/
- .github/workflows/deploy.yml
- astro.config.mjs
- README.md
- .gitignore

It intentionally DOES NOT include:
- package.json
- package-lock.json
- node_modules/

Keep the package.json and package-lock.json generated by your existing Astro installation.

After extracting:
1) npm run dev
2) Check the homepage and all /projects/* pages.
3) npm run build
4) Commit and push.
5) GitHub Settings -> Pages -> Source must be GitHub Actions.
