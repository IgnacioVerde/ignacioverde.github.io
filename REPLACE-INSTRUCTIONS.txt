PORTFOLIO BILINGUAL UPDATE
==========================

1. Extract this ZIP directly over your existing portfolio repository.
2. Allow Windows to replace existing files.
3. Keep your existing package.json, package-lock.json and node_modules.
4. Run:

   npm run dev

5. Test:
   http://localhost:4321/
   http://localhost:4321/es/

6. Check the EN / ES button on the home page and on each case study.
7. Commit and push through GitHub Desktop.

Included changes:
- Full Spanish version of the home page.
- Full Spanish versions of all six case studies.
- EN / ES language switch that preserves the current route.
- hreflang metadata for English/Spanish pages.
- Fix: "software:architecture" spacing issue.
- Fix: ShibusenRO now correctly says the second executable updates the launcher.
